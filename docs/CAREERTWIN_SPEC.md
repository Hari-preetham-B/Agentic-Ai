# CareerTwin Unified Intelligence Specification — Phase 8

## Overview

Phase 8 transforms CareerTwin from a collection of isolated intelligence
systems into a unified, evolving career state.

## Core Concept

```
User-confirmed profile
  + Uploaded evidence
  + Career requirements
  + Skill-gap analysis
  + Learning progress
  + Interview performance
        ↓
   CareerTwin State
        ↓
Cross-system intelligence
        ↓
Career recommendations, Learning priorities, Interview priorities,
Career readiness, Evidence-aware explanations
        ↓
Updated derived CareerTwin state
```

## Source-of-Truth Hierarchy

1. User-confirmed profile data
2. User-confirmed edits
3. Uploaded/documented information
4. Deterministic derived calculations
5. Evidence-backed external information
6. Interview performance signals
7. Agent inference

## State Classification

Each piece of information is classified as one of:
- CONFIRMED: User explicitly provided or confirmed
- DOCUMENTED: Extracted from uploaded user documents
- DERIVED: Calculated by deterministic application logic
- EVIDENCE_BACKED: Supported by the evidence system
- PERFORMANCE_SIGNAL: Derived from interview/learning behavior
- INFERRED: Generated by reasoning, not independently confirmed

## CareerTwin State Model

The unified state includes:
- Profile summary (name, status, headline)
- Education, experience, projects
- Confirmed skills (user-confirmed)
- Documented skills (extracted from documents)
- Target careers and active target
- Career fit (score, readiness, strengths, weaknesses, blockers)
- Skill gaps (matched/partial/missing with priority)
- Roadmap summary (counts, status, staleness)
- Interview summary (sessions, performance, strengths, weaknesses)
- Evidence summary (claim counts by status)
- Cross-system insights
- Conflicts
- Stale state indicators
- Readiness level and score
- Last updated timestamp

## Career Fit Engine

Combines:
- Skill match score
- Required skill coverage
- Important missing skills
- Prerequisite blockers
- Interview performance signals
- Documented evidence

Readiness levels: NOT_READY, EARLY, DEVELOPING, COMPETITIVE, STRONG

## Cross-System Insight Engine

Generates typed insights from structured signals:
- SKILL_GAP: Missing core skills
- INTERVIEW_WEAKNESS: Interview performance gaps
- ROADMAP_PRIORITY: Critical learning items
- CAREER_ALIGNMENT: Strong profile-career alignment
- INTERVIEW_IMPROVEMENT: Areas for improvement

Each insight includes: id, type, severity, title, reason, affected entity,
source signals, recommended action, classification.

## Conflict Detection

Detects:
- PERFORMANCE_GAP: Interview performance vs confirmed skill proficiency
- GOAL_CONFLICT: Multiple career targets vs active target

Conflicts are reported, not silently resolved. User-confirmed data is never
overwritten by derived signals.

## State Reconciliation

Determines which derived systems need regeneration based on triggers:
- profile_skill_changed → skill_gap, career_fit, readiness, roadmap, insights
- interview_completed → interview_performance, readiness, insights
- evidence_updated → evidence_insights
- career_target_changed → career_fit, skill_gap, roadmap, readiness, insights
- roadmap_regenerated → insights

## Freshness / Staleness

Derived state includes freshness information:
- generated_at: when the derived state was created
- source_updated_at: when the source data was last updated
- is_stale: whether the derived state is outdated
- reason: why it's stale

## Refresh Behavior

POST /careertwin/refresh determines stale components and generates a refresh
plan. Does not blindly regenerate everything.

## CareerTwin Agent

Produces a typed explanation layer over deterministic state. LLM may generate
narrative/explanations but never calculates scores, insights, conflicts,
or state.

## Tools

- `get_careertwin_state` — retrieve unified state
- `calculate_career_readiness` — calculate readiness
- `get_careertwin_insights` — get cross-system insights
- `get_careertwin_conflicts` — get conflicts
- `get_stale_derived_state` — get stale components
- `refresh_careertwin_state` — generate refresh plan

## APIs

- `GET /careertwin` — unified state
- `GET /careertwin/insights` — insights
- `GET /careertwin/conflicts` — conflicts
- `GET /careertwin/readiness` — readiness
- `GET /careertwin/stale` — stale state
- `POST /careertwin/refresh` — refresh
- `POST /agent-runs` with `careertwin_analysis` capability

## Frontend

- `/app/twin` — unified CareerTwin view with:
  - Active career target, readiness, skill count
  - Current signal (strongest skill, biggest gap, interview weakness, roadmap priority)
  - Career position (fit score visualization)
  - Skill gaps (top missing skills)
  - Insights (cross-system)
  - Conflicts
  - Navigation to Career Intelligence, Skill Gap, Roadmap, Interview
